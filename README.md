# Portfolio Sprint Countdown — GitHub Pages files

This folder is ready to publish as a static GitHub Pages site. It contains `index.html` and the two image files referenced by the page.

After these files are in the root of a GitHub repository, enable Pages in the repository settings and choose the main branch and root folder. GitHub will provide an `https://<account>.github.io/<repository>/` address; use that public HTTPS address in Handshake. A local `file:///` path is only available on this computer and will be rejected.
